Authentication & Status Codes

All /api/v1/* endpoints (except /api/v1/health) and /mcp accept either a personal Bearer token or an active browser cookie session.

  • Authorization: Bearer frd_<token> — recommended for CI/CD, scripts, and MCP clients
  • 401 Unauthorized — missing, invalid, or revoked token/session ({"error": "..."})
  • 403 Forbidden — admin privileges or token ownership required
  • 409 Conflict — initial admin /setup has not been completed yet

Quick curl Examples

export FREUD_TOKEN="frd_your_token"

# Trigger a flow and read execution status
curl -s -X POST -H "Authorization: Bearer $FREUD_TOKEN" \
  {{.BaseURL}}/api/v1/flows/etl-example.yaml/run

# Inspect execution & task logs
curl -s -H "Authorization: Bearer $FREUD_TOKEN" \
  {{.BaseURL}}/api/v1/executions/<run_id>

# MCP tool discovery over HTTP
curl -s -X POST -H "Authorization: Bearer $FREUD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  {{.BaseURL}}/mcp
